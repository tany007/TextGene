# TextGene Application - Quick Setup Guide

## What's Included
- `javafx-21-complete.zip` - JavaFX runtime libraries
- `text-gene-ui-uber.jar` - TextGene application
- `run-textgene.bat` - Application launcher

## Installation Steps

### Step 1: Extract JavaFX
1. Extract `javafx-21-complete.zip` to `C:\Java\`
2. After extraction, verify this directory exists: `C:\Java\javafx-21-complete\lib`

### Step 2: Install Java (if not already installed)
- Download and install Java 21 or newer from: https://adoptium.net/
- This is required to run the application

### Step 3: Run TextGene
- Double-click `run-textgene.bat` to start the application

## Troubleshooting

**If the application doesn't start:**
- Make sure Java 21+ is installed: Open Command Prompt and type `java -version`
- Verify JavaFX directory exists: `C:\Java\javafx-21-complete\lib`
- Check that all files are in the same folder

**Error: "Java not found"**
- Install Java 21 from https://adoptium.net/
- Restart your computer after installation

**Error: "JavaFX not found"**
- Make sure you extracted `javafx-21-complete.zip` to `C:\Java\`
- The correct path should be: `C:\Java\javafx-21-complete\lib`

## System Requirements
- Windows 10 or newer
- Java 21 or newer
- At least 512MB available RAM
